## 🐋 关于我

- 🎓 **中传（CUC）**：课程笔记、项目、踩过的坑都从这儿长出来，主线一直是**数据 → 模型 → 真能跑起来的工具**
- 🔭 **正在做**：DeepSeek Harness（DSH）插件，让本地智能体顺手一点 —— 权限自动切换、向量记忆、消息自动回复
- 🎵 **老本行**：AI 音乐生成与深度学习复现，从可控音乐 Transformer、MusicGen 到 MAE、Keras-GAN，笔记攒了一路
- 🕷️ **也做过**：微博爬虫 + 舆情分析，用户、话题、评论一网打尽，配情感分析和关系网络图
- 🎮 **偶尔折腾**：在 Unreal Engine 4 里搭 3D roguelike
- 💬 一句原则：**把喜欢的事做成能跑的东西**
